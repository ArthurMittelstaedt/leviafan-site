# leviafan.fr

Site of the Leviafan studio, published by GitHub Pages at https://leviafan.fr.

- `content/`: the texts (Markdown), the source of the legal pages, English and French.
- `build.py`: builds the pages (`python build.py`), then commit the result.
- `app-ads.txt`: the AdMob account allowed to sell the ads of the studio's apps.
